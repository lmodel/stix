# Policies

* [Security policy](security-policy.md) - How to report a vulnerability (GitHub's private vulnerability reporting), which release receives fixes (the latest), what executes in the repository and what holds each surface, the ruleset on `main`, and the two repository settings that are not yet in force.
* [Licence and attribution](license-and-attribution.md) - The repository's licences: Apache-2.0 for the schema and code, CC BY 4.0 for the knowledge bundle, BSD-3-Clause for OASIS's JSON schemas and examples under `upstream/`, and the STIX specification cited, never copied.
* [AI covenant](ai-covenant.md) - The rules for AI-assisted contributions: the contributor owns what they submit, an element says what STIX says and cites its section, the specification's text is never copied, `upstream/` is never edited, and the scheduled librarian's changes always go through a person's review.
