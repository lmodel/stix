# Glossary

* [STIX Domain Object (SDO)](domain-object.md) - In STIX, a STIX Domain Object (SDO) is a higher-level concept of threat intelligence, such as a campaign, an indicator or a threat actor. The schema renders each as a subclass of `StixDomainObject`, which a knowledge concept may name as its type.
* [STIX Relationship Object (SRO)](relationship-object.md) - In STIX, a STIX Relationship Object (SRO) links other objects: `StixRelationship` joins a source to a target by a relationship type, and `StixSighting` records that a domain object was seen.
* [STIX Cyber-observable Object (SCO)](cyber-observable-object.md) - In STIX, a STIX Cyber-observable Object (SCO) records a fact observed on a network or host, such as a file, an IP address or a process. The schema renders the eighteen as subclasses of `StixCyberObservableObject`.
* [STIX bundle](bundle.md) - In STIX, a bundle carries a set of STIX objects together for transport, and is not itself a STIX object. The schema renders it as `StixBundle`, the tree root, whose `objects` may be any concrete STIX object class.
* [Open vocabulary](open-vocabulary.md) - In STIX, an open vocabulary (a name ending in `-ov`) suggests values for a property but accepts any other string, while a closed enumeration (`-enum`) does not. The schema renders an open vocabulary as an enum that a slot names beside `string`.
* [STIX identifier](stix-identifier.md) - In STIX, every object's `id` is its type name, two hyphens and a UUID, such as `indicator--8e2e2d2b-17d4-4cbf-938f-98ee46b3cd3f`. The schema types it as `stix_identifier`, and each class narrows it to its own type prefix.
* [Marking definition](marking-definition.md) - In STIX, a marking definition states a data marking, such as a copyright statement or a Traffic Light Protocol (TLP) level, that objects apply through `object_marking_refs` or granular markings. The schema renders it as `StixMarkingDefinition`.
* [Extension](extension.md) - In STIX, an object's `extensions` dictionary holds its extensions: the predefined extensions of some cyber-observable objects, such as `ntfs-ext`, and extensions an extension definition (`StixExtensionDefinition`) defines, keyed by that definition's identifier.
