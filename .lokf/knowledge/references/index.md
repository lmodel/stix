# References

* [STIX Version 2.1 (OASIS Standard)](stix-2-1-specification.md) - Structured Threat Information Expression (STIX) Version 2.1, the OASIS Standard of 10 June 2021 that the schema renders, at docs.oasis-open.org. STIX 2.1 Errata 01 exists only as a Committee Specification Draft, so the schema follows the approved standard.
* [OASIS STIX 2.1 JSON schemas](oasis-stix-json-schemas.md) - oasis-open/cti-stix2-json-schemas, the repository where OASIS publishes JSON schemas and examples for STIX 2.1 under the BSD-3-Clause licence, with no releases; `upstream/` copies it at a pinned commit.
* [Unified Cyber Ontology (UCO) 1.5.0](uco-1-5-0.md) - The Unified Cyber Ontology (UCO) 1.5.0, released by ucoProject under Apache-2.0, whose class and property IRIs the schema's mappings name under UCO's own namespaces, such as `https://ontology.unifiedcyberontology.org/uco/observable/`.
